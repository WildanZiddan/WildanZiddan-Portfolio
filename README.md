# Right-click index.html → Open with Live Server

## 📬 Contact Form Setup

This portfolio uses [FormSubmit](https://formsubmit.co/) for the contact form. To configure it for your own email:

1. In `index.html`, find the form action:
```html
<form action="https://formsubmit.co/your@email.com" method="POST">
```
2. Replace `your@email.com` with your own email address
3. Submit the form once — FormSubmit will send a confirmation email to activate it
